# Play Store listing import files

## Translations CSV (AI / Gemini upload)

Primary file:
`play-store-listings-translations.csv`

Alternate headers:
`play-store-listings-translations-locale-columns.csv`

### How to import in Play Console

1. Open **Grow users → Store presence → Main store listing** (or **Translations → Store listings and products**).
2. Use **Manage translations** / Gemini **upload CSV or Google Sheet** if shown.
3. Upload `play-store-listings-translations.csv` (UTF-8 with BOM).
4. Review each language (title ≤30, short ≤80, full ≤4000) and apply.

If Gemini upload asks for a Sheet: open the CSV in Google Sheets and share/paste that Sheet instead.

### Locales included

en-US, ar, es-ES, es-419, fr-FR, de-DE, pt-BR, it-IT, id, fil, hi-IN, ur, ru-RU, tr-TR, th, ja-JP

Brand name **Kafi** is kept untranslated in titles except Arabic (**كافي**).
