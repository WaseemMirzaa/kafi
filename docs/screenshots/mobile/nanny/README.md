# Kafi — Nanny Flow (mock mode)

The **complete, self-contained** nanny journey, in order — from welcome through signup, onboarding, review, and the approved-nanny app. Screens shared with the other flow (welcome, OTP, create-password, notifications, terms, privacy, password-reset, delete-account) are shown here **in this flow's own context** — e.g. themed and populated for the nanny (rose theme, nanny-perspective notifications). Captured in mock mode with a seeded **approved** demo nanny so every screen shows real data.

**23 screens.** Full-height, content-cropped images.
