# Kafi — Family Flow (mock mode)

The **complete, self-contained** family journey, in order — from welcome through signup, the job/family form, browsing & unlocking nannies, shortlist, messaging, applicants, trials, subscription, and profile. Screens shared with the other flow (welcome, OTP, create-password, notifications, terms, privacy, password-reset, delete-account) are shown here **in this flow's own context** — e.g. themed and populated for the family (purple theme, family-perspective notifications). Captured in mock mode with a seeded demo family session so data screens show real content.

**23 screens.** Full-height, content-cropped images.
